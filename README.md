# XAU SmartZones — Indicator ทองคำส่วนตัว (MT5)

Indicator สำหรับ XAUUSD บน MetaTrader 5 ที่
1. **ตีโซน Demand / Supply ให้อัตโนมัติ**
2. **ให้สัญญาณ BUY / SELL** เมื่อราคากลับมาทดสอบโซนแล้วมีแท่งเทียนปฏิเสธ
3. **บอก Entry / SL / TP1 / TP2** และคะแนนคุณภาพ (A / B / C)
4. มี **Panel สรุปสถานะตลาด** มุมซ้ายบน และแจ้งเตือน (Popup / เสียง / มือถือ)

> ทุกอย่างคำนวณจาก **แท่งที่ปิดแล้วเท่านั้น** ลูกศรที่ขึ้นแล้วจะไม่หายหรือย้ายที่ (non-repaint)

## 1. หลักการทำงาน

### 1.1 โซน Demand / Supply มาจากไหน
ใช้แนวคิด **Base → Impulse** (ฐานก่อนราคาวิ่งแรง)

```
 Demand                               Supply
           ▲▲▲  ← ขาวิ่งขึ้นแรง            ▓▓▓▓  ← ฐาน (base) = SUPPLY
          ▲                                    ▼
         ▲      (≥ 1.8 × ATR)                   ▼   (≥ 1.8 × ATR)
  ▓▓▓▓  ← ฐาน (base) = DEMAND                    ▼▼▼ ← ขาวิ่งลงแรง
```

- **Impulse (ขาวิ่ง)**: แท่งเทียนสีเดียวกันติดกัน 1–5 แท่ง ที่วิ่งรวมกัน ≥ `1.8 × ATR`
- **Base (ฐาน)**: แท่งก่อนขาวิ่ง (บวกแท่งตัวเล็กก่อนหน้าได้อีกไม่เกิน 3 แท่ง) → นี่คือที่ที่ "เงินก้อนใหญ่" เข้าซื้อ/ขาย
- **Demand** = จาก Low ของฐาน ถึงตัวเทียนบนสุดของฐาน
- **Supply** = จาก High ของฐาน ถึงตัวเทียนล่างสุดของฐาน
- ทุกค่าวัดเป็น **ATR** จึงปรับตัวเองได้ทั้งตอนทองนิ่งและตอนข่าวแรง ไม่ต้องตั้งเป็นจุด

### 1.2 อายุของโซน
| สถานะ | เงื่อนไข | สีบนกราฟ |
|---|---|---|
| สด (Fresh) | ยังไม่เคยถูกแตะ | เขียว / แดง เข้ม |
| ถูกทดสอบ | ราคาเคยเข้ามาแตะแล้ว (`T1`, `T2` …) | สีหม่นลง |
| แตก (Broken) | **ปิดแท่ง** ทะลุโซนเกิน 0.1 ATR | หายไป (หรือเทา ถ้าเปิด `InpShowBroken`) |
| หมดแรง | แตะเกิน 3 ครั้ง หรืออายุเกิน 600 แท่ง | หายไป |

ป้ายโซนจะเขียนเช่น `DEMAND ** T1 2341.20-2343.80`
- `*` = ความแข็งแรง: 1 ดาวพื้นฐาน, +1 ถ้าขาวิ่งเบรกโครงสร้าง (BOS), +1 ถ้าขาวิ่งแรง ≥ 2.5 ATR
- `T1` = ถูกแตะมาแล้ว 1 ครั้ง

### 1.3 สัญญาณ BUY (SELL กลับด้านทั้งหมด)
ต้องผ่าน **ทุกข้อ** บนแท่งที่ปิดแล้ว:
1. ราคาย่อลงมาแตะ **โซน Demand** ที่ยังไม่แตก และเป็นการแตะครั้งที่ 1–2
2. แท่งนั้นเป็น **แท่งปฏิเสธ**: ไส้ล่างยาว ≥ 35% ของแท่งและปิดครึ่งบน หรือเป็น **Bullish Engulfing**
3. **เทรนด์ TF ใหญ่** (ค่าเริ่มต้น H1) เป็นขาขึ้น: EMA50 > EMA200
4. อยู่ใน **ช่วงเวลาเทรด** (ลอนดอน–นิวยอร์ก)
5. **มีที่ให้วิ่ง**: ระยะถึงโซน Supply ถัดไปต้อง ≥ 1.5R ไม่งั้นไม่ให้สัญญาณ
6. คะแนนรวม ≥ 60

### 1.4 คะแนน (Score) และเกรด
| ปัจจัย | คะแนน |
|---|---|
| พื้นฐาน | 40 |
| โซนเกิดจากการเบรกโครงสร้าง (BOS) | +15 |
| ขาวิ่งแรง ≥ 2.5 ATR (หรือ ≥ 2.0 ได้ +5) | +10 |
| แตะครั้งแรก (โซนสด) | +10 |
| ตรงเทรนด์ TF ใหญ่ | +15 |
| แท่งปฏิเสธแรง (Engulfing / ไส้ ≥ 55% / ตัวเทียน ≥ 0.8 ATR) | +10 |

**A ≥ 80** (ดีที่สุด) · **B 65–79** · **C 60–64**

### 1.5 SL / TP คิดยังไง
- **Entry** = ราคาปิดของแท่งสัญญาณ (หรือเข้าตอนเปิดแท่งถัดไป)
- **SL** = ใต้ขอบล่างโซน − 0.25 ATR (ต่ำสุด 0.5 ATR, ถ้าไกลเกิน 3 ATR จะไม่ให้สัญญาณ)
- **TP1** = 1R → แนะนำปิดครึ่งหนึ่ง แล้วเลื่อน SL มาที่ทุน
- **TP2** = 2R หรือ **ขอบโซนฝั่งตรงข้าม** ถ้าใกล้กว่า

## 2. ติดตั้งใน MT5 (ทำครั้งเดียว)

> ผมคัดลอก `XAU_SmartZones.ex5` เข้าโฟลเดอร์ MT5 ของ FBS ในเครื่องให้แล้ว ถ้ามองเห็นใน Navigator แล้วข้ามไปข้อ 3 ได้เลย

1. เปิด MT5 → เมนู **File → Open Data Folder**
2. เข้าไปที่ `MQL5\Indicators\` แล้ววางไฟล์ `XAU_SmartZones.mq5` (และ `.ex5` ถ้ามี)
3. กลับมาที่ MT5 → หน้าต่าง **Navigator** (กด `Ctrl+N`) → คลิกขวาที่ **Indicators** → **Refresh**
4. ถ้ามีแค่ `.mq5`: ดับเบิลคลิกเปิดใน MetaEditor แล้วกด **F7** (Compile) ต้องขึ้น `0 errors`

## 3. ใส่ลงกราฟ

1. เปิดกราฟ **XAUUSD** และเลือก Timeframe — แนะนำ **M15** (เทรดรายวัน) หรือ **H1** (ถือนานขึ้น)
2. ลาก **XAU_SmartZones** จาก Navigator ไปวางบนกราฟ
3. แท็บ **Common**: ติ๊ก ✅ *Allow algo trading* ไม่จำเป็น (indicator ไม่ส่งออเดอร์)
4. แท็บ **Inputs**: ปรับค่าตามข้อ 5 หรือใช้ค่าเริ่มต้นก่อน → **OK**

| กราฟที่เปิด | ตั้ง `InpHTF` (TF ใหญ่) |
|---|---|
| M5 | M30 หรือ H1 |
| **M15 (แนะนำ)** | **H1** |
| H1 | H4 |

> ถ้ากราฟเป็นพื้นขาว ให้เปลี่ยนสีโซนในหมวด **หน้าตา** เป็นสีอ่อน เช่น Demand `C'200,235,220'`, Supply `C'245,210,215'`

## 4. อ่านกราฟและเทรด

**Panel มุมซ้ายบน:**
```
XAU SMART ZONES  XAUUSD M15
HTF H1 trend: BULLISH (UP)        ← ฝั่งที่ควรเทรด
Structure   : UPTREND (HH/HL)     ← โครงสร้างบน TF ปัจจุบัน
ATR(14)     : 4.85                ← ความผันผวนต่อแท่ง (ดอลลาร์)
Demand near : 2341.20-2343.80 (5.3 away)
Supply near : 2360.00-2362.10 (13.6 away)
Last signal : BUY A85 @2344.10
  2026.11.19 15:30  SL 2339.80  TP 2352.00
Session     : OPEN
Bias BUY: wait pullback to DEMAND ← ตอนนี้ควรทำอะไร
```

**ขั้นตอนเทรดแนะนำ**
1. ดูบรรทัดสุดท้ายของ Panel ก่อน — ถ้าเขียน `stand aside` หรือ `Out of session` = **อย่าเทรด**
2. รอราคาเดินเข้าโซน (Panel จะขึ้น `>> IN DEMAND: watch BUY trigger`)
3. **รอลูกศรเขียว ▲ / แดง ▼** ขึ้นหลังแท่งปิด — ห้ามเข้าก่อนแท่งปิด
4. เข้าออเดอร์ตามเส้นบนกราฟ: เส้นเทาประ = Entry, แดง = SL, ฟ้าประ = TP1, น้ำเงิน = TP2
5. ถึง TP1 ปิดครึ่ง + เลื่อน SL มาทุน ส่วนที่เหลือปล่อยไป TP2
6. **ขนาดล็อต**: เสี่ยงไม่เกิน 1% ต่อไม้  
   `ล็อต ≈ (ทุน × 1%) ÷ (ระยะ SL เป็นดอลลาร์ × 100)`  
   เช่น ทุน $1,000, SL ห่าง $5 → 10 ÷ 500 = **0.02 ล็อต**
7. เน้นเกรด **A/B** ถ้าอยากได้เฉพาะสัญญาณดีสุด ตั้ง `InpMinScore = 80`
8. ระวังข่าวแรง (NFP, CPI, FOMC) — ปิดจอก่อนข่าว 15 นาที ถึงหลังข่าว 15 นาที

## 5. ค่าที่ควรรู้ (Inputs)

| ค่า | ค่าเริ่มต้น | ปรับยังไง |
|---|---|---|
| `InpImpulseATR` | 1.8 | เพิ่ม (2.2) = โซนน้อยลงแต่แข็งแรงขึ้น · ลด (1.5) = โซนเยอะขึ้น |
| `InpZonesPerSide` | 4 | จำนวนโซนที่แสดงต่อฝั่ง |
| `InpRequireBOS` | false | true = เอาเฉพาะโซนที่เบรกโครงสร้าง (คุณภาพสูง จำนวนน้อย) |
| `InpMinScore` | 60 | 80 = เฉพาะเกรด A |
| `InpMaxTouchSignal` | 2 | 1 = เทรดเฉพาะโซนสด |
| `InpTrendFilter` | EMA | OFF = สัญญาณสวนเทรนด์ด้วย (เสี่ยงขึ้น) |
| `InpMinRR` | 1.5 | ที่ว่างขั้นต่ำถึงโซนตรงข้าม |
| `InpTargetRR` | 2.0 | TP2 สูงสุดกี่ R |
| `InpUseSession` | true | ให้สัญญาณเฉพาะช่วงเวลาที่ตั้ง |
| `InpSessionStart/End` | 9 / 23 | **เวลาเซิร์ฟเวอร์ MT5** (ดูที่ Market Watch) |

**เรื่องเวลา**: เซิร์ฟเวอร์ FBS ส่วนใหญ่เป็น GMT+2 (หน้าหนาว) / GMT+3 (หน้าร้อน)  
เวลาไทย = เวลาเซิร์ฟเวอร์ + 5 ชม. (หน้าหนาว) หรือ + 4 ชม. (หน้าร้อน)  
ค่า 9–23 ≈ **14:00–04:00 น. เวลาไทย** = ช่วงลอนดอนเปิดถึงนิวยอร์กใกล้ปิด ซึ่งเป็นช่วงทองวิ่งดีที่สุด

## 6. แจ้งเตือนเข้ามือถือ
1. ติดตั้งแอป **MetaTrader 5** บนมือถือ → Settings → Messages → คัดลอก **MetaQuotes ID**
2. บนคอม: **Tools → Options → Notifications** → ติ๊ก Enable → วาง ID → Test
3. ใน Inputs ของ indicator ตั้ง `InpAlertPush = true`

## 7. ทดสอบย้อนหลังก่อนใช้จริง
1. **View → Strategy Tester** (`Ctrl+R`) → เลือก **Indicator** → `XAU_SmartZones`
2. Symbol XAUUSD, Timeframe M15, ช่วง 3–6 เดือน, ติ๊ก **Visual mode** → Start
3. ดูว่าลูกศรขึ้นตรงไหน ชนะ/แพ้ยังไง จดสถิติอย่างน้อย 30–50 สัญญาณก่อนใช้เงินจริง
4. ใช้กับ **บัญชี Demo** ก่อนเสมอ

## 8. ใช้กับ EA (สำหรับต่อยอด)
```mql5
int h = iCustom(_Symbol, PERIOD_M15, "XAU_SmartZones");
double dir[1], sl[1], tp[1], score[1];
CopyBuffer(h, 2, 1, 1, dir);   // +1 = BUY, -1 = SELL, 0 = ไม่มี (แท่งที่ปิดล่าสุด)
CopyBuffer(h, 3, 1, 1, sl);    // SL
CopyBuffer(h, 4, 1, 1, tp);    // TP2
CopyBuffer(h, 5, 1, 1, score); // คะแนน
```
Buffer: `0` ลูกศร Buy · `1` ลูกศร Sell · `2` ทิศ · `3` SL · `4` TP · `5` Score · `6` ATR
